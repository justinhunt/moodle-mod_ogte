version 1.1.0 (Build: 2026111102)
guests can use the Text Profiler and the Text Rewriter's analysis again: mod/ogte:use is now a read capability, since Moodle never gives guests a write capability
new setting to log front page visitors in as guest before the page loads, replacing the redirect from inside the embedded OGTE tools
new Text Generator: choose a word list, level, length, fiction or non-fiction, a description and words to include; the text is written at the level and checked and repaired like the Text Rewriter's, with a keyword list and its figures
only word lists whose levels have sentence targets are offered in the Text Generator
new Text Rewriter: analyse a text against every level of a word list, then simplify it to a chosen level, with up to 3 automatic repair passes checked by the profiler
word list levels can have targets for the rewriter (cefr, avgsentence, maxsentence, description); the NGSL 1.2 list gets them on upgrade
the rewriter prompts can use each level's targets as placeholders ({cefr}, {maxsentence}, {avgsentence}, {toprank}, {maxwords} ...), listed with descriptions on the prompt edit page
the prompt edit page has a live preview: pick a word list and level and see each placeholder's value and the exact prompt that would be sent, without calling the AI
now requires Moodle 4.5
the AI tools call the site's own AI provider (OpenAI, Gemini or DeepSeek) instead of Cloud Poodll
the AI prompts, token limits and reasoning effort can be edited on a new AI prompts admin page
new capabilities mod/ogte:useai and mod/ogte:manageprompts
removed the Cloud Poodll API user and secret settings
restored the access checks on the coverage web service
AI errors are now shown to the user instead of leaving the spinner running
